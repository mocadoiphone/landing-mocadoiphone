# Moça do iPhone — pacote inicial

Arquivos:
- `BRAIN-MOCA-DO-IPHONE.md`: documento normativo do projeto.
- `agents/`: agentes responsáveis por arquitetura, dados, desenvolvimento, UI/UX, segurança, QA e relatórios.

Uso sugerido:
1. Coloque a pasta na raiz do repositório.
2. Instrua os agentes a lerem o Brain antes de qualquer implementação.
3. Toda alteração estrutural deve gerar uma decisão MDI-Dxxx.
4. Não publique conteúdo migrado sem revisão do cliente.
